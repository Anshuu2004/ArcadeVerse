# 🛠️ Contributor Pre-Flight Submission Validator

> An automated pre-flight verification portal that validates folder structure rules, verifies file prerequisites, and generates exact copy-paste JSON snippets for `assets/js/games-registry.js` for **ArcadeVerse (Nexus Spring of Code – Winter Edition 2026)**.

## ⚡ Problem Solved
New contributors frequently run into PR rejection due to:
- Placing loose files directly in the root directory.
- Forgetting the mandatory folder format `games/<game-name>_<contributor-name>/`.
- Missing syntax commas or invalid categories in `assets/js/games-registry.js`.

## 🚀 Features
- **Dynamic Syntax Checking**: Real-time regex testing of game and username slugs.
- **Auto-Generated Registry Snippets**: One-click copying of properly structured JSON objects.
- **Rule Verification Checklist**: Visual indicators confirming compliance with NSoC '26 contribution criteria.
