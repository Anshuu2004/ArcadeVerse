# Leaderboard Export & Champion Certificate Generator

A client-side reporting and reward generation module for ArcadeVerse Hall of Fame.

## Features
- **Format Flexibility**: Exports live leaderboard tables as structured CSV or formatted JSON.
- **HTML5 Canvas Certificate Generator**: Programmatically generates high-resolution, custom retro cyber certificates with watermark, auth hash, player score, and rank.
- **Offline Direct Download**: Utilizes dynamic Blob creation and Object URLs for immediate zero-network file downloads.
- **Strict Isolation**: Self-contained within `leaderboard-export-babin/`.
