## 🎮 Overview

The Player Stats & Achievement Telemetry Engine introduces a gamified reward layer for players exploring ArcadeVerse. It automatically tracks game launches, distinct game variety, and portal visits to unlock achievements with animated toast notifications and a dedicated navbar HUD modal.

---

## ⚡ Key Features

- **5 Distinct Unlockable Achievements:**
  - 🪙 **Insert Coin:** Launch your first web arcade game.
  - 🎮 **Arcade Explorer:** Play at least 3 distinct community games.
  - 💡 **Idea Collector:** Visit the Open Game Ideas Vault.
  - 🏆 **Hall of Fame Scout:** Explore the live Contributor Leaderboard.
  - ⚡ **Arcade Veteran:** Launch 10+ game sessions.
- **Dynamic Achievement Toast Notifications:** Animated celebration toasts alerting users upon criteria fulfillment.
- **Navbar HUD & Badge Counter:** Trophy icon in the header showing the current number of unlocked awards.
- **Progress Gauge:** Visual completion bar tracking platform mastery.
- **LocalStorage State Persistence:** All stats persist seamlessly across sessions (`arcadeverse_player_stats`).
