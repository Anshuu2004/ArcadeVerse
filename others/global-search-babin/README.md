# Global Omnibar & Command Palette Search Engine

A global keyboard-driven command palette and game search modal for ArcadeVerse.

## Features
- **Keyboard Shortcuts**: Activate anytime using `Ctrl + K`, `Cmd + K`, or `/` from any page.
- **Fuzzy Search Across Ecosystem**: Indexes game titles, genres, and documentation.
- **Keyboard Traversal**: Navigate results with Arrow keys (`↑` / `↓`) and launch with `Enter`.
- **Isolated Module**: Lives cleanly inside `global-search-babin/`.
