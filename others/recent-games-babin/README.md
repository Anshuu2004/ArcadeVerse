# Recently Played & Quick Resume Drawer

A persistent client-side tracking and slide-out drawer module for ArcadeVerse.

## Features
- **Local History Persistence**: Tracks the last 6 played games with categories and relative timestamps in `localStorage`.
- **Slide-out Cyber Drawer**: Provides a clean slide-out panel with game badges, elapsed time ("5m ago"), and instant 1-click play actions.
- **Deep-Link Auto Relaunch**: Automatically resolves current page game elements or routes to `index.html?game=<id>`.
- **History Management**: Includes a 1-click "Clear History" action with instant UI refresh.
- **Strict Isolation**: Contained entirely within `recent-games-babin/`.
