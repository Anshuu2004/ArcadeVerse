FOR CONTRIBUTORS

Why Build in ArcadeVerse?

Designed specifically for NSOC contributors to build meaningful mini-games without overhead.

📁

Isolated Directory Structure

Every game lives in its dedicated subfolder inside games/<your-game>/. No risk of merge conflicts with fellow participants.

👥

Multiple Variants Welcomed

Want to build your own variant of Snake or Tetris? Simply use snake-(your-handle) so everyone's version shines!

⚡

Zero Framework Overhead

Pure Vanilla HTML, CSS, JavaScript & Canvas APIs. Master core web skills that top engineering teams value most.

🎖️

Verified Recognition

Every approved PR is spotlighted in the Hall of Fame and the dynamic contributor leaderboard with git handles.

Quick Workflow

How to Contribute in 4 Easy Steps

1

Fork & Clone

Fork the repository, clone it locally, and checkout a feature branch:

git checkout -b feature/my-new-game
2

Build Your Game

Create games/<game-name>/ with index.html, style.css, and game.js.

3

Register in Registry

Add your game entry to assets/js/games-registry.js and sign CONTRIBUTORS.md.

4

Submit PR

Commit, push to your fork, and open a Pull Request to NSOC main branch!
