🚀 Add Your Game to ArcadeVerse

Follow these 4 simple steps to have your game featured in our live arcade catalog:

Step 1

Fork & Create Branch

git checkout -b game/my-cool-game
Step 2

Create Your Game Directory in games/

Put your game inside games/<your-game>/ (or games/<your-game>-<your-name>/ if multiple people build similar games):

games/my-cool-game/index.html
games/my-cool-game/style.css
games/my-cool-game/game.js
Step 3

Use our Built-in PR Snippet Generator

Scroll down to the Automated PR Generator section, fill in your details, and paste the generated snippet into assets/js/games-registry.js.

Step 4

Commit & Open PR!

git add .
git commit -m "feat(game): add my-cool-game by @username"
git push origin game/my-cool-game
