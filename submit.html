4-Step Submission Workflow

Follow these guidelines for an instant merge from project admins

Step 1

Fork & Branch

Fork the repository to your account, clone locally, and checkout a branch:

git checkout -b game/game-name_contributor-name
Step 2

Create Your Game Subfolder in games/ (Strict Notation)

Must strictly follow the pattern: games/game-name_contributor-name/ to prevent collisions.

games/game-name_contributor-name/index.html
games/game-name_contributor-name/style.css
games/game-name_contributor-name/game.js
Step 3

Paste Snippet into assets/js/games-registry.js

Use the code generated above and append it to the GAMES_REGISTRY array, then sign your row in CONTRIBUTING.md.

Step 4

Commit, Push & Open PR

git add .
git commit -m "feat(game): add game-name by @contributor-name"
git push origin game/game-name_contributor-name
