## 🎮 Overview

The Theme Customizer & Retro CRT Scanline Engine introduces a personalized visual customization suite to ArcadeVerse. Players can select between 4 curated neon palettes (Cyber Cyan, Synthwave Sunset, Matrix Emerald, Solar Amber) and activate an authentic curved CRT scanline monitor overlay.

---

## ⚡ Key Features

- **4 Curated Cyberpunk Palettes:** Dynamic live switching modifying root CSS variables across all components seamlessly.
- **Hardware-Accelerated CRT Shader:** Lightweight scanline pattern and vignette overlay delivering authentic retro arcade ambiance without performance lag.
- **Navbar Integration:** Palette trigger button in navigation bar with an accessible flyout drawer.
- **LocalStorage Persistence:** Remembers user theme and scanline preferences across all pages.
