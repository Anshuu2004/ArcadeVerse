SCORING & TIER ARCHITECTURE

How Contributor Work Is Evaluated & Rewarded

A multi-dimensional arcade scoring system designed to reward complete playable games, advanced game mechanics, platform features, and quality contributions.

Notice: In-Application Arcade Score vs. Official NSoC '26 Program Points

In-Application Points: The points and badges shown across ArcadeVerse (+100, +30, +25, +15) are gamified in-app arcade points designed to rank contributors on the ArcadeVerse Hall of Fame, celebrate playable game creators, and grant dynamic developer badges.

Official NSoC '26 Program Points: Official Nexus Spring of Code winter edition points are completely separate. Official evaluation follows NSoC level labels on your merged GitHub Pull Requests (Level 1: 3 pts, Level 2: 5 pts, and Level 3: 10 pts) tracked by program mentors.

DATA ENGINE ARCHITECTURE

How the Application Fetches & Calculates Contributor Scores

ArcadeVerse operates client-side with real-time verification and zero third-party databases. Here is how metrics are fetched and computed:

01

Live GitHub REST API

Queries /repos/DebasmitaBose0/ArcadeVerse/contributors to fetch verified merged contributors, commit counts, and profile avatars in real time.

02

Games & PR Registry Audit

Cross-references GAMES_REGISTRY to verify playable games in games/ and inspects tags for dynamic canvas mechanics, physics, and AI.

03

Multi-Tier Badges Engine

Computes the total score and automatically awards highest badges across both Games Dedicated and Milestones categories simultaneously.
