How Contributor Work Is Evaluated & Rewarded

A transparent scoring system strictly aligned with official NSoC Winter Edition 2026 Level 1 (3 pts), Level 2 (5 pts), and Level 3 (10 pts) guidelines.

+3 pts

Level 1 Contribution

Awarded for documentation, typo fixes, guides, code comments, and minor bug fixes.

3 pts × Level 1 PR
+5 pts

Level 2 Contribution

Awarded for UI/UX improvements, responsive layouts, CSS components, and navigation redesigns.

5 pts × Level 2 PR

10 pts × Level 3 PR / Game
