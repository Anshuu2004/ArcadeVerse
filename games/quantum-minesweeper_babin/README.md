## 🎮 Overview

Quantum Minesweeper is a cyberpunk reimagining of classic minefield deduction. Built using recursive flood-fill algorithms, guaranteed first-click safety, and responsive CSS Grid styling, players must locate and isolate hazardous subatomic singularities across configurable sectors.

---

## ⚡ Game Mechanics & Features

- **Guaranteed First-Click Safety:** Mines are generated procedurally after the player's initial click, ensuring the starting tile and surrounding cluster are never trapped.
- **Recursive Flood-Fill Engine:** Zero-hazard blank tiles recursively uncover adjacent safe sectors.
- **Dual Sector Difficulties:** Quick 9x9 (10 Mines) or challenge 12x12 (20 Mines) grid configurations.
- **Touch-Friendly Flag Toggle:** Mobile players can toggle between excavation mode and hazard marking mode with a dedicated tap control.
- **Real-Time HUD Telemetry:** Active mine counters, dynamic elapsed timer, and retro status face indicator.
- **How to Play Modal:** Built-in rules and controls overlay for Project Admin review.

## 🕹️ Controls

| Action | Desktop Mouse | Touch / Mobile |
| :--- | :--- | :--- |
| **Excavate Sector** | Left Click | Tap Tile (Flag Mode OFF) |
| **Mark Hazard Flag** | Right Click | Tap Tile (Flag Mode ON) |
| **Reset Sector** | Click Face Icon | Tap Face Icon |
